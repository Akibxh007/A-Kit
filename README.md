## ✨ Overview

**A-Kit** is a lightweight, privacy-first Android utility suite built natively with **Kotlin** and **Jetpack Compose**. Designed for power users, it works **100% offline** with **zero ads, zero trackers, and zero cloud dependencies**.

---

## 🚀 Core Modules

| Module | Key Capabilities |
| :--- | :--- |
| **⚡ Power & Thermal Telemetry** | Real-time charging wattage (`W`), live amperage (`mA`), single-cell voltage (`V`), battery temperature monitoring, and **Dual-Cell / Charge-Pump (2S)** calibration toggle. |
| **🌙 Charging AOD (Always-On Display)** | Pitch-black AMOLED charging screen with 12-hour clock, live charging speed, and burn-in protection. |
| **🧹 SnapClean** | Smart background screenshot detector and auto-cleaner to keep your gallery clutter-free. |
| **📡 Drop Wi-Fi Share** | High-speed local P2P & Offline Hotspot file/snippet sharing with QR 1-tap pairing, browser fallback, and real-time chunked transfer progress (`MB/s`). |

---

## 🔒 Privacy & Permissions

A-Kit does **not** request internet access for telemetry or analytics. All permissions are used strictly on-device:
* **Camera:** Scanning local Drop QR codes for instant peer pairing.
* **Location / Nearby Wi-Fi Devices:** Creating and discovering local offline Wi-Fi hotspots for peer-to-peer file sharing.
* **Storage / Media:** Saving received files to `Downloads/A-Kit` and detecting screenshots in `SnapClean`.
